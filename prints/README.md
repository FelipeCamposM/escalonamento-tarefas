# Evidencias visuais

As imagens desta pasta sao produzidas por um navegador Brave em modo headless,
carregando a aplicacao real em `http://127.0.0.1:5173`.

- `01-visao-geral.png`: abertura em desktop.
- `02-laboratorio.png`: instancia aleatoria executada ao vivo, Gantt e DAG.
- `03-prazo-inviavel.png`: decisao negativa para prazo 7.
- `04-experimentos.png`: benchmark e tabela comparativa.
- `05-mobile.png`: verificacao responsiva em 390 x 844.

Para refazer:

```powershell
npm run dev
npm run screenshots
```
